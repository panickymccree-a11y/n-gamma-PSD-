# EJ-276D 参数化 n/γ PSD 演示

**当前版本说明（以下旧版本参数说明仅作历史记录）：** 运行 `demo_ngamma_psd.m`，默认保留当前 1250 MS/s、14 位 ADC；旧脚本备份为 `demo_ngamma_psd_previous.m`。若需原 125M 平台，修改 `p.fsMHz=125`。

依据 [Eljen EJ-276D 产品网页](https://eljentechnology.com/index.php/products/loadedscintillators/79-ej-256)，三分量 γ 衰减时间为 [13,35,270] ns，中子为 [13,59,460] ns；电子光产额 8600 photons/MeV、发射峰 425 nm、密度 1.099 g/cm³。[2025 年目录第18页](https://eljentechnology.com/images/technical_library/Eljen-Catalog-2025-01-web.pdf)的中子第二项为 50 ns，与网页 59 ns 不同，默认采用网页值，可修改 `p.tauNeutron(2)=50` 做敏感性检查。这是 EJ-276D 参数，不能套用全部 EJ 型号。时间常数不等于脉冲宽度。

模型改为三个面积归一化核 `(exp(-t/tau_i)-exp(-t/tauRise))/(tau_i-tauRise)` 的加权和。厂家未公布权重：γ [0.80,0.15,0.05]、中子 [0.65,0.23,0.12] 均为假设积分光量比例，不是指数幅度比例。事件间权重扰动标准差 0.012，截断后归一化；有效上升常数 3 ns、前端低通 5 ns、增益、噪声、触发残差也未标定。仅使用前三个分量。光产额、发射峰、密度只作为元数据保存，未模拟光子统计、光收集、PDE 或传感器单光电子响应。

记录至 1600 ns，总积分 0–1200 ns、尾积分 50–1200 ns；延长窗口用于容纳长尾，窗口未经优化。有限窗仍损失部分电荷，积分能量未经有限窗校准。三种方法保持不变，250 keVee 评价仍采用真值 225–275 keVee 选窗，同样本定阈值与分类。MAT 的 p 保存来源和完整参数。本版本属于“厂家时间常数 + 假设权重与读出”模型，不能作为 EJ-276D 实测 FOM 的预测。

## 旧版本说明

在 MATLAB 中打开并运行 `demo_ngamma_psd.m`，无需额外工具箱。

流程：双衰减脉冲 → 一阶低通 → 噪声与 ADC 量化 → 基线扣除 → 总电荷/尾电荷积分 → PSD 散点、分布、阈值甄别与 FOM。

默认 125 MS/s，每类 6000 个事件，能量 100–600 keVee。γ 与中子的差异通过慢分量积分占比（0.10 / 0.28）体现；脉冲面积随能量线性变化。顶部 `p` 参数可直接调整采样率、快慢时间常数、慢分量占比及波动、电子学低通、噪声、ADC、触发残差与积分窗口。

输出在 `demo_output`：两张 PNG、可编辑 FIG、逐事件 CSV 与完整 MAT 数据。

## 三种方法并列展示

保留当前参数设置（14 位 ADC、尾积分从 56 ns 开始），同一条基线扣除后的波形同时计算：

| 方法 | 特征定义 |
| --- | --- |
| 尾部电荷比 | `Qtail / Qtotal` |
| 电荷加权平均时间 | 总积分窗内 `sum(t .* V) / sum(V)`，单位 ns；使用带符号电压 |
| 下降时间 | 峰后从 80% 峰值下降到 20% 峰值的时间差，交越点线性插值，单位 ns |

峰值在 0–80 ns 内搜索，下降沿在总积分窗内寻找首次交越；未找到交越的事件记为 NaN，并排除该方法统计。未额外进行平滑，噪声可能使下降时间的首次交越提前。各方法分别报告有效样本数；当前没有优化时间窗或幅度比例，因此排序仅适用于当前参数。

新增 `psd_methods_comparison.png/.fig`：三列分别对应三种方法，三行分别为能量散点、225–275 keVee 分布和混淆矩阵。`fom_vs_energy.png` 改为三方法 FOM 曲线，`method_comparison.csv` 汇总 FOM、阈值、同样本准确率和有效事件数；事件 CSV 增加 `meanTime` 与 `fallTime`。MAT 文件另保存三种预测、混淆矩阵及能量分箱 FOM。

下降沿时间类 PSD 的相关研究：[Performance of real-time neutron/gamma discrimination methods](https://doi.org/10.1007/s41365-022-01160-5)。本演示的 80%–20% 定义属于具体实现选择，并非复现该文参数。

FOM = 两类 PSD 均值间距 / 两类 FWHM 之和，FWHM 由标准差乘 2.35482 估算。适用于近似高斯分布；本演示没有执行高斯拟合。250 keVee 的结果使用真值能量 225–275 keVee 选窗；横轴积分能量只作近似估计，没有额外做有限积分窗的能量标定。阈值和混淆矩阵使用同一批窗口内事件，仅演示流程，不代表独立测试性能。

这些参数未经实际塑闪、光电传感器和前端标定，不能证明真实探测器 250 keVee 下 FOM > 1.2。这里把 250 keV 按电子等效能量 keVee 解释；如果指标指入射中子能量，需要另建能量沉积、淬灭和响应映射。真实器件验证需要实测波形/材料参数校准。
