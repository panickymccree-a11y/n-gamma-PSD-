# MATLAB 连续 n/γ 合成波形模型

## 入口与用途

运行 [`../MATLAB_Pulse/main.m`](../MATLAB_Pulse/main.m)，参数统一在 [`pulse_config.m`](../MATLAB_Pulse/pulse_config.m) 修改。脚本包从本地 AWG 波形生成工程迁入，替换原根目录的 `demo_ngamma_psd.m`。

本包生成连续采样记录、事件类别与顺序、实际事件的三分量图，以及可供 AWG 导入的 CSV。原脚本中的能量窗、三种 PSD 方法、分类准确率和 FOM 对比不属于本包功能；在线 Host 的尾部电荷比 PSD 功能保持独立。

## 默认配置

| 参数 | 默认值 |
|---|---|
| 模式 | `mixed`，近 1:1 γ/中子标签后随机置换 |
| 采样率 / 总点数 | 75 MSa/s / 3,200,000 |
| 单脉冲窗口 / 事件间隔 | 2800 ns / 200 ns |
| 上升常数 / 收尾起点 | 3 ns / 2500 ns |
| γ 三分量衰减常数 | [13, 35, 270] ns |
| 中子三分量衰减常数 | [13, 59, 460] ns |
| γ / 中子幅度权重 | [0.80, 0.17, 0.03] / [0.65, 0.27, 0.08] |
| 事件峰值 / 峰值波动 | 0.8 / ±5%，逐事件均匀分布 |
| 时间常数波动 | ±10%，三个衰减常数与上升常数分别独立均匀波动 |
| 全记录噪声 RMS | 0.02，归一化之前的相对幅度单位 |
| 随机种子 | 20261012 |

窗口和间隔按采样间隔四舍五入到整数点数。默认分别为 210 点和 15 点，完整周期数为 14,222，γ/中子各 7111 个；剩余不足一周期的记录尾部保持干净基线，并同样加入全记录噪声。

75 MSa/s 是合成/AWG 文件的采样率，与 FPGA 的 125 MS/s 采样率不是同一参数。若将波形用于 AWG→模拟前端→ADC 验证，应分别设置 AWG 回放和 ADC 采样条件。

## 波形与混排方法

每分量为 `weight * (1-exp(-t/rise)) * exp(-t/tau)`，每个采样区间用 32 个中点平均。三个分量共用末尾半余弦收尾窗，窗口末点为零；三分量之和再按该事件的目标采样峰值统一缩放。这里的权重是幅度系数，不是积分光量或电荷占比。

混排模式先生成数量相差不超过一个的两类标签，再用固定种子随机置换；允许连续多个同类事件。各事件独立产生峰值和时间常数波动，按固定周期写入连续记录。随后加入去均值、精确 RMS 缩放的高斯噪声；有噪声和无噪声记录使用同一归一化除数，避免分别缩放造成幅度关系改变。

## 导出

结果位于 `MATLAB_Pulse/output/`，不提交到 Git。每次运行会覆盖同名文件。

- `waveform.mat`：配置、完整波形、噪声、事件标签及代表性三分量。
- `waveform.csv`：默认含噪声 AWG 文件；开启 `export_clean` 可另导出干净波形。
- `waveform.csv.json`：配置、实际窗口/间隔、缩放除数和噪声 RMS。
- `event_order.csv`：类别、事件起始点/时间、缩放前峰值和实际时间常数。
- `figure_1/2.png` 与 `.fig`：分量及连续混排图。

AWG CSV 有 13 行头部，最后一行为 `xpos,value`，记录频率为 `采样率/总点数`，默认 23.4375 Hz。写入临时文件后检查头部、连续点号、有限值及总行数，再替换目标文件。该校验验证文件结构，不代表任意 AWG 型号均已完成兼容性验证。

## 适用范围

这是可调的三分量合成模型，幅度权重、上升与噪声参数没有经过真实探测器标定；未完整模拟光子统计、光收集、PDE、SiPM 响应或能量沉积。事件类别是合成标签，不能将其直接视作实测分类真值或探测器性能证明。

MATLAB 与 NumPy 的随机数算法和调用顺序不同，同一随机种子不保证与原 Python 波形逐点相同。本包的文件和图形检查也不替代 AWG/FPGA 硬件回放验证。
