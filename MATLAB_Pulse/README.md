# MATLAB 合成脉冲脚本包

在 MATLAB 打开本目录的 `main.m`，点击运行即可。不需要 Python、GUI 或 VBS，不依赖额外工具箱。本脚本包替换仓库原来的 `demo_ngamma_psd.m`，用于连续波形合成与 AWG 导出；不包含原脚本的三方法 PSD/FOM 对比。

## 参数与启动

所有参数集中在 `pulse_config.m`。`mode` 支持 `mixed`（γ/中子混排）、`gamma`、`neutron`、`custom`；两类的三分量时间常数和权重均可分别修改。默认采样率 75 MSa/s、320 万点、脉冲窗口 2800 ns、间隔 200 ns、噪声 RMS 0.02。修改后重新运行 `main.m`。每次运行覆盖本包 `output` 内的同名结果，需要保留时请先复制或重命名结果。

## 混排与模型

1. 按完整周期数建立交替类别标签，γ/中子数量差不超过1；奇数时 γ 多一个。
2. 用固定随机种子置换标签。随机混排允许连续多个同类事件，不强制交替。
3. 每事件峰值独立均匀波动；三个衰减常数和上升常数分别独立均匀波动。
4. 每分量为 `weight*(1-exp(-t/rise))*exp(-t/tau)`，每采样区间32个中点平均，共同乘末尾半余弦窗，再按合成采样峰值归一化。
5. 各事件写入连续序列；窗口末点回到基线，间隔和不足完整周期的记录尾部维持基线。
6. 全记录加入去均值、精确 RMS 缩放的高斯噪声；干净和含噪声记录共用一个缩放除数以避免削顶。

沿用旧版的合成模型和默认参数，但 MATLAB 与 NumPy 随机数算法/调用不同，同种子不保证与旧文件逐点相同。权重是幅度系数，不是积分电荷占比；模型不代表实测拟合。

## 查看结果

- `figure_1.png/.fig`：当前存在类别各自首个实际脉冲的快、中、慢三分量和总和。减去基线并仅为显示前补500 ns；三分量之和与该实际事件一致。单类别模式只画实际存在类别。
- `figure_2.png/.fig`：上方连续含噪声序列和无噪声序列，颜色表示类别；每段保留到下一事件首点的连接，因此类别切换不再出现空值断点。下方按时间列出事件编号和类别。默认看前12个事件，可改 `preview_events`。预览不抽点，CSV保留全记录。
- `event_order.csv`：全部事件类别、1起始的采样点号、0起始时间、缩放前峰值及实际时间常数。实际导出峰值还需除以 `result.divisor`。
- `waveform.mat`：完整配置、连续波形、噪声、类别标签、首事件三分量和事件表，可在 MATLAB 继续分析。
- `waveform.csv`：默认导出含噪声 AWG 文件。开启 `export_clean` 后另导出无噪声文件。CSV保留13行头部及 `xpos,value`，`frequency=采样率/总点数`；写入临时文件并检查头部、点号、有限数值和行数后替换目标文件。对应 `.csv.json` 记录配置、取整后的窗口/间隔和缩放信息。
