# Vivado IP

The current project uses two IP configurations referenced by
`single_channel_mca.xpr`:

- `mca_clk_wiz/mca_clk_wiz.xci`: derives the 125 MHz and 200 MHz internal clocks
  from the board's 125 MHz input.
- `mca_peak_divider/mca_peak_divider/mca_peak_divider.xci`: divider used by the
  peak interpolation path.

The `.xci` files are the project inputs. Generated HDL wrappers, simulation
models, vendor libraries, XML exports, checkpoints and netlists are omitted
from the source repository and regenerated by Vivado 2020.2. The retained
`mca_vio` directory is from an earlier project state and is not referenced by
the current RTL or XPR.

For standalone simulation, `HDL/sim/mca_ip_stubs.sv` provides the required
behavioral IP stand-ins. See `../README.md` for the toolchain setup.
